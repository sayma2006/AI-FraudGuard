# AI-FraudGuard

AI-FraudGuard is a real-time credit card fraud detection system built using XGBoost and FastAPI.

## Features

- Real-time fraud prediction
- Fraud probability estimation
- XGBoost machine learning model
- FastAPI REST API
- Web-based transaction checking interface
- Input validation using Pydantic
- Inference-time measurement

## Technology Stack

- Python
- XGBoost
- Scikit-learn
- Pandas
- FastAPI
- Uvicorn
- Jinja2
- HTML
- CSS
- JavaScript
